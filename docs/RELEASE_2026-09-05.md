# Release checks — 2026-09-05

- Destination plan finder is shared by country pages, unless explicitly disabled in the page settings.
- Payment confirmation checks the stored checkout session, amount and currency.
- Stripe test payments do not automatically purchase real eSIMs unless their exact order ID is listed in the server variable `ESIM_GO_TEST_ORDER_IDS`. Existing provider feature gates still apply. No keys or flags were enabled in this release.
- Delivery recovery reads an existing confirmed provider order only. Unknown transactions require manual provider reconciliation; never submit another purchase to resolve them.
- Provider callbacks and usage refreshes are serialized per ICCID and use atomic database updates. Ambiguous bundle assignments stop for reconciliation.
- Admin: `/admin/orders/attention` lists unresolved delivery/usage work. A failed old callback must not overwrite a newer sync; inspect and refresh the profile rather than forcing replay.
- Run `npx tsx --test scripts/purchase-safety.test.ts`, TypeScript, lint and production build before merging.
- These checks do not substitute for a separately approved live end-to-end purchase, installation and usage test. No real purchase or customer email is triggered by these tests.
