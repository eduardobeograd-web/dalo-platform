# DALO project priorities

## Critical before real top-ups

- Separate the installed eSIM profile from purchased data bundles in the data model.
- One eSIM profile, identified by its ICCID, must support multiple compatible bundles and orders.
- Store the eSIM reuse deadline separately from every bundle's activation deadline and expiry date.
- Group all bundles belonging to the same eSIM in the customer dashboard.
- Show customer-facing labels such as `eSIM reusable until`, `Activate by`, `Plan valid until`, and `Purchased`.
- Connect `Buy more data` and `Add another destination` only after eSIM Go confirms compatibility for the existing ICCID.
- Never sell a bundle as a top-up when a new eSIM installation is actually required.
